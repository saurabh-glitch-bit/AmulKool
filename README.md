🥛 Amul Kool — Flavored Milk Landing Page

A modern, responsive product landing page inspired by Amul Kool, designed to showcase flavored milk products with an engaging and visually appealing user interface.

The project focuses on creating a premium product experience using clean frontend development, smooth interactions, responsive layouts, and attractive product visuals.

🌸 Live Demo

🚀 "View Live Website" (https://saurabh-glitch-bit.github.io/AmulKool/)

📌 About the Project

Amul Kool is a frontend web project that recreates a modern flavored-milk product landing page.

The website presents a visually rich product experience with product imagery, flavor selections, animations, and responsive layouts suitable for both desktop and mobile devices.

✨ Key Highlights

- 🥛 Modern flavored-milk product showcase
- 🌸 Attractive product-focused landing page
- 📱 Fully responsive design
- 🎨 Clean and modern UI
- ⚡ Smooth user interactions
- 🖼️ High-quality product visuals
- 🍫 Multiple flavor/product options
- 🎬 Product reveal animation/video
- 💻 Built with vanilla frontend technologies

🎨 Features

🥤 Product Showcase

Displays flavored milk products in a visually engaging product-focused layout.

🌈 Flavor Selection

The interface provides different flavor/product options, allowing users to explore the available variants.

📱 Responsive Design

The website is designed to adapt to different screen sizes, providing a consistent experience across desktops, tablets, and mobile devices.

✨ Interactive UI

JavaScript is used to add dynamic behavior and improve the overall user experience.

🎬 Product Animation

The project includes a product-reveal visual/video element to create a more engaging presentation.

🚀 Getting Started

1. Clone the Repository

git clone https://github.com/saurabh-glitch-bit/AmulKool.git

2. Navigate to the Project

cd AmulKool

3. Run the Project

Since this is primarily a frontend project, you can open:

index.html

directly in your browser.

For the best development experience, use VS Code with Live Server.
